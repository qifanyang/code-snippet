块级元素和行内元素是HTML元素在文档流中两个基本的显示模式。它们在页面布局中有着不同的行为和特性。

块级元素（Block-level Elements）：
特点：

    独占一行，从上至下垂直排列。
    宽度默认为父元素的100%。
    可以设置宽度、高度、边距、内边距等属性。
    可以包含其他块级元素和行内元素。
示例：

<div>、<p>、<h1>、<ul>、<li>等。
html
Copy code
<div>
  <p>This is a block-level element.</p>
  <ul>
    <li>Item 1</li>
    <li>Item 2</li>
  </ul>
</div>

行内元素（Inline Elements）：
特点：

    不会独占一行，水平排列，相邻的行内元素会在同一行显示。
    宽度只取决于元素的内容。
    不能设置宽度和高度，边距上下不生效，水平方向的边距和内边距可以生效。
    只能包含文本或其他行内元素。
示例：

<span>、<a>、<strong>、<em>、<img>等。
html
Copy code
<p>This is an <span>inline element</span> within a block-level element.</p>
区别总结：
    块级元素独占一行，可以包含其他块级元素和行内元素，常用于页面布局。
    行内元素水平排列，只能包含文本或其他行内元素，用于修饰文本或嵌套在块级元素中。
    在CSS中，可以通过 display 属性来修改元素的显示模式，将块级元素转为行内元素，反之亦然。
