z-index 是 CSS 中用于控制元素在垂直层级上显示顺序的属性。通过设置元素的 z-index 值，可以改变元素在层叠上下文中的层级关系，从而决定哪个元素显示在哪个元素的前面。

主要用途包括：

控制层叠顺序： 主要功能是定义元素在垂直方向上的显示顺序。z-index 值较大的元素会覆盖在值较小的元素之上。

处理重叠元素： 在页面布局中，有时元素可能会重叠在一起。通过调整 z-index，可以确保特定元素显示在其他元素的前面，以解决重叠问题。

实现图层效果： 在一些交互性的页面或动画效果中，通过适当地使用 z-index 可以实现图层切换、弹出框显示等效果。

实现导航菜单和弹出框： 在创建导航菜单、弹出框或模态框时，z-index 用于确保这些元素显示在其他页面内容之上。

.modal {
position: fixed;
z-index: 1000; /* 设置较高的 z-index，确保弹出框在顶层 */
}

.overlay {
position: fixed;
z-index: 999; /* 设置次高的 z-index，确保蒙层在弹出框之下但在其他内容之上 */
}

.header {
z-index: 100; /* 设置相对较高的 z-index，确保头部在主体内容之上 */
}

.content {
z-index: 1; /* 设置较低的 z-index，确保主体内容在底层 */
}


需要注意的是，z-index 只在定位元素（position: relative/absolute/fixed）之间才会生效。如果元素没有设置定位属性，z-index 不会产生任何效果。
