sentinel作为流量控制,保护被访问的资源(比如方法, 代码块),类似并发编程的共享资源访问控制

并发控制规则简单: 互斥,可重入, 一般硬编码完成, 比如: new Semaphore(10)
sentinel规则: QPS, 超时, 异常(比例或个数), 降级, 动态更新规则...

资源
- 资源名称, 标识用于资源识别,作为统计的标识
- Entry, 对应资源的抽象组件, 实现具体功能
- Entry创建(框架自动适配创建, 注解创建, API显示创建)
- Entry创建时同时创建一系列功能插槽(slot chain), 责任链模式动态扩展处理者能力
- slot chain扩展接口ProcessorSlot, SPI做为扩展

功能插槽
- StatisticSlot: 滑动窗口LeapArray, 实时秒级统计指标

规则  
- 流量控制规则:QPS(默认)或线程, 直接拒绝(默认)/排队等待
- 熔断降级规则:慢调用比例(默认)或异常比例/异常数
    - 慢调用比例: 单位统计时长(statIntervalMs)内请求书大于最小请求数,且慢调用比例大于阈值, https://github.com/alibaba/Sentinel/blob/master/sentinel-demo/sentinel-demo-basic/src/main/java/com/alibaba/csp/sentinel/demo/degrade/SlowRatioCircuitBreakerDemo.java#L70
    - 异常比例:异常只的业务异常
    - 异常数:
- 热点参数规则:比如用户 ID 为参数，针对一段时间内频繁访问的用户 ID 进行限制

核心API
- SphU
- Sph0
